## 📖 Detailed Descriptions

### 1. IBM Hadoop 101
* **Issuing Organization:** Cognitive Class (Powered by IBM Developer Skills Network)
* **Course Code:** `BD0111EN`
* **Issue Date:** August 23, 2026
* **Verification URL:** [https://courses.cognitiveclass.ai/certificates/b145de5e3e0849d1b5a40a0e464b7c42](https://courses.cognitiveclass.ai/certificates/b145de5e3e0849d1b5a40a0e464b7c42)
* **Direct File:** [`certificates/IBM_Hadoop_101.pdf`](certificates/IBM_Hadoop_101.pdf)
* **Description:**
  A comprehensive foundational course covering the architecture and mechanics of **Apache Hadoop**. The course provides deep insight into how distributed storage and processing handle massive-scale datasets across commodity hardware clusters.
* **Key Topics & Skills Covered:**
  - **HDFS (Hadoop Distributed File System):** NameNode, DataNode architecture, block replication, data integrity, and fault tolerance.
  - **MapReduce Framework:** Mapper and Reducer workflows, parallel computation, shuffle & sort phases, and distributed job execution.
  - **Hadoop Ecosystem:** Overview of Pig, Hive, HBase, Sqoop, Flume, Oozie, and ZooKeeper.
  - **Cluster Management:** YARN (Yet Another Resource Negotiator) resource allocation and scheduling.
